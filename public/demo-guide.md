# 온담 업무실 ver2 발표·시연 안내

총 11개 순서, 80단계입니다. 전체 기본 자동 시연은 약 11–14분이며, 발표 중 설명하는 시간에 따라 달라집니다.

## 입력 없이 자동으로 보여주는 방법

1. http://127.0.0.1:5173/ 에서 상단 **자동 시연**을 누릅니다.
2. 전체 시연 또는 원하는 업무 하나를 선택합니다. 기본 6초, 발표용 10초, 빠르게 1.5초 중 설명 시간을 고릅니다.
3. **선택한 순서 자동 시작**을 누르면 화면 이동, 예시 입력, 저장·승인과 결과 확인까지 자동 진행됩니다.
4. 아래 설명 패널의 **일시정지**로 설명 시간을 확보하고 **계속 재생**으로 이어갑니다. **다음**은 현재 처리 후 설명 대기 시간을 넘깁니다.
5. **종료·원래대로**를 누르면 시연 시작 전 업무 데이터·역할·글자 설정·화면으로 돌아갑니다. 각 장은 같은 샘플로 시작하므로 개별 시연도 가능합니다.

시연 중에는 화면의 입력·버튼을 따로 조작하지 않는 것이 좋습니다. 직접 체험하려면 먼저 종료하세요. 자동 시연은 가상 데이터만 사용하며, 실제 전화·문자·카카오톡·결제·인쇄는 실행하지 않습니다. 새로고침하면 업무 데이터는 초기화됩니다.

## 발표 시작 멘트

> “오늘 보실 화면은 한의원 고객관리와 내부 운영을 연결한 디자인 시안입니다. 원장과 직원의 화면을 나누고, 조제·재고·연락·문진·휴가가 어떻게 이어지는지 보여드리겠습니다. 현재 입력값은 모두 가상 데이터입니다.”

**4. 화면 설정 적용**

**5. 통합 검색**

**6. 초안 이어쓰기**

**7. 아침 브리핑**

- 설명할 말: 예약 환자의 문진과 준비사항을 정리해 봅니다. 인쇄 버튼은 수동으로 사용할 수 있습니다.

### 02 · 재료 부족부터 조제 완료까지

**7. 저장 처방으로 새 초안**

- 설명할 말: 새 처방에서 자주 쓰는 약재 구성을 불러옵니다.
- 화면에서 확인: 저장 처방 A · 인삼과 감초

**8. 초안 저장과 상태 필터**

- 설명할 말: 완료 전에는 초안으로 저장하고 작성 중인 처방만 모아볼 수 있습니다.

### 09 · 휴가 신청·승인·취소

시작 화면: `#leave`. 각 순서를 개별 재생해도 아래 예시가 동일하게 준비됩니다.

**1. 직원 화면과 기존 신청**

- 설명할 말: 직원 A로 바꾸어 본인의 신청만 관리합니다.
- 화면에서 확인: 직원 메뉴에서 원장 경영 숨김

**2. 승인 전 신청 철회**

- 설명할 말: 아직 승인되지 않은 신청은 직원이 철회할 수 있습니다.
- 화면에서 확인: 기존 9월 29일 신청 철회

**3. 날짜로 신청 일수 자동 계산**

- 화면에서 확인: 신청 일수 자동 3일 · 시안은 주말·공휴일 포함

**4. 반차 자동 계산**

**5. 연차 신청 입력**

- 설명할 말: 다시 3일 연차로 바꾸고 사유와 인계사항을 입력합니다.
- 화면에서 확인: 9월 28–30일 · 3일 · 인계 메모

**6. 승인 전에는 달력 미표시**

- 설명할 말: 신청 후 승인 대기 상태가 되고 공유 달력에는 아직 나타나지 않습니다.
- 화면에서 확인: 내 신청 승인 대기 · 달력에는 직원 B만 표시

**7. 원장 승인 대기함**

- 설명할 말: 한승재 원장이 신청과 인계사항, 같은 기간 다른 직원의 휴가를 확인합니다.
- 화면에서 확인: 직원 B의 9월 30일 휴가 중복 기간 안내

**8. 승인 후 달력 반영**

- 설명할 말: 원장이 승인하면 직원 달력에 자동 표시됩니다.

**9. 반려와 사유**

- 설명할 말: 다른 신청을 반려할 때는 직원이 확인할 사유를 남깁니다.
- 화면에서 확인: 직원 C 신청 반려 · 검토 의견 기록

**10. 다른 직원의 사유 보호**

- 설명할 말: 직원 A가 직원 B의 일정을 열어도 개인 사유와 인계 내용은 보이지 않습니다.
- 화면에서 확인: 이름·기간·휴가 종류·일수만 공유

- 설명할 말: 이미 승인된 휴가는 바로 없애지 않고 원장에게 취소 요청을 보냅니다.
- 화면에서 확인: 직원 A 취소 요청

**12. 취소 승인 후 달력에서 제거**

- 설명할 말: 취소 검토 중에는 달력에 남습니다. 원장이 취소를 승인하면 사라집니다.
- 화면에서 확인: 직원 A 취소 완료 · 직원 B 일정 유지

## 휴가 일수 기준

- 9월 28일–30일은 시작일·종료일을 포함하여 **3일** 자동 입력됩니다.
- 같은 날은 1일, 오전·오후 반차는 0.5일입니다. 반차의 종료일은 시작일과 같습니다.
- 시안에서는 주말·공휴일을 포함합니다. 실제 근무표에 따른 연차 차감·잔여량 계산은 다음 개발 단계에서 연결합니다.
