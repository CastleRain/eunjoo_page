# A 소프트 브라운 · Phase 4 검토

사용자가 선택한 A 배치에 흰색과 연한 갈색을 적용했습니다. 웜그레이 시안 검토 후 사용자가 한의원 분위기의 부드러운 갈색을 다시 선택했습니다. 16px 컴팩트 모드를 최초 기본값으로 사용하며, 기존에 저장한 18/20/22px 선호는 보존합니다. 18px는 기존 '기본' 프리셋 이름을 유지하며, 시연에서도 이 프리셋을 사용합니다.

- 이전 웜그레이 시안 기록(현재 갈색 테마 적용 전 캡처): http://127.0.0.1:8841/warm-gray.html
- 개발 브랜치: feature/ui-redesign-warm-gray
- 원본 태그: pre-redesign-20260927
- 선택 당시 A: design/option-a-linen

## 적용 범위

모든 메뉴의 제목, 패널, 표, 검색/탭, 버튼, 달력, 상세 창과 공통 내비게이션에 공유 색상 토큰을 적용했습니다. 흰색 표면, 옅은 갈색 선택 영역, 차분한 갈색 버튼을 사용합니다. 컴팩트 모드는 표·카드·업무 행의 간격도 줄입니다. 모바일의 작은 모드에서도 주요 버튼·탭은 최소 44px 높이를 유지합니다. 큰 글씨에서는 rem 기반 간격과 표 여백이 다시 늘어납니다. 경고/오류/안내 등의 의미가 있는 상태 색상은 유지합니다.

## 기능 확인

웜그레이 단계에서 전체 자동 시연이 83/83 단계 완료됐습니다. 종료 후 16px 컴팩트 화면과 시연 전 데이터가 복원됐고, 새로고침 후에도 설정이 유지됩니다. 이후 소프트 브라운 변경은 색상 토큰과 문서/페이지 제목에 한정되며, 해당 변경에서 빌드와 대표 화면을 다시 확인했습니다.

- 원본 A와 JSX 이벤트 처리 174개를 비교해 그대로임을 확인했습니다.
- 보호 대상 Sites 파일 및 기존 업무 시연 스크립트/휴가 계산 파일은 변경하지 않았습니다.
- 기존 테스트 7개 통과. 휴가 계산·Sites 패키징 테스트이며 전체 UI 커버리지를 뜻하지 않습니다.
- 빌드 성공. 큰 JS 번들 경고는 기존부터 남아 있으며 이번 범위에서 코드 분할은 하지 않았습니다.
- 프로젝트에 별도 lint/typecheck 스크립트가 없습니다. JSX 프로젝트로, TypeScript 전환은 하지 않았습니다.

## 변경 종류 및 의존성

Phase 4에서 새 의존성 추가 없음. Phase 3에서 승인된 Ant Design·Lucide·Motion·Noto Sans KR을 그대로 사용합니다.

`pre-redesign-20260927` 대비 JSX/JS 파일도 변경되었습니다. 아이콘 import 교체, 대표 화면의 마크업, 테마와 색 토큰, 공통 화면 클래스가 대상입니다. 이번 추가 동작은 사용자가 요청한 **표시 설정(16px 선택·초기값·밀도 표시)**에 한정됩니다. 업무 데이터·라우트·입력/저장/승인 콜백은 바꾸지 않았습니다.

main 병합, push, 공개 배포는 하지 않았습니다. 검토 후 명시적 승인 시에만 Phase 5로 진행합니다.
