## 확인 및 복구

각 브랜치는 `pre-redesign-20260927`에서 시작합니다. 태그는 `f0f9a8e` 원본을 가리킵니다. main과 공개 배포에는 반영하지 않았습니다.

현재 A는 프로젝트 루트, B·C는 별도 Git worktree에서 동시에 실행 중입니다. worktree에 연결된 브랜치는 다른 폴더에서 바로 checkout할 수 없으므로 현재는 위 링크로 비교합니다. 나중에 별도 체크아웃이 필요하면 `git worktree add --detach <새 폴더> design/option-a-linen`처럼 해당 커밋을 독립적으로 열 수 있습니다. 원본 작업으로 돌아갈 때는 변경사항을 확인한 뒤 루트에서 `git switch main`을 사용합니다. 파괴적인 reset은 실행하지 않습니다.

- A에서 기본 제공 전체 시연 83/83 단계 완료, 종료 후 오늘 화면 복원, 브라우저 오류 로그 없음.
- A 새 약재 등록 → H005 생성·0g 시작 → 입고 연결 → 2포장×250g=500g 반영, 중복 인삼 등록 거부를 직접 확인.

- C 입고 등록 500g 반영 및 데스크톱·모바일 재고/오늘 화면 확인.
- A 모바일 메뉴 열기와 재고 이동 확인. 세 안의 1440×1040 데스크톱 및 390×844 모바일 스크린샷 저장.
- 원본과 JSX 이벤트 핸들러 174개를 AST로 비교해 동일함을 확인. 자동 시연 스크립트, 휴가 계산 모듈, Sites 보호 파일에 변경 없음.
- 나머지 메뉴의 전체 리디자인과 최종 전수 UI 검증은 선택안 확정 후 Phase 4 범위입니다.
